Install guide

インストール手順

Creatte Tool を入れるときに、Mac や Windows が「確認できませんでした」という注意を出すことがあります。この手順どおりに進めれば、5分ほどで使い始められます。

?

なぜ注意が出るの？

Mac や Windows は、ネットからダウンロードしたアプリを開くとき、開発元が Apple や Microsoft に登録されているかを確かめます。Creatte Tool はこの登録（有料の署名）をしていないため、念のための注意が出ます。故障やウイルスの知らせではありません。Creatte Tool の中身はすべて GitHub で公開されていて、だれでも確認できます。

Mac

Mac に入れる

注意は「ダウンロードしたファイルを開くとき」と「アプリを初めて開くとき」の2回出ます。どちらも、設定画面で「このまま開く」を押せば進めます。

  1. ファイルをダウンロードする

    ダウンロード欄の「Mac 版をダウンロード」を押します（ここから直接ダウンロードもできます）。ファイルは「ダウンロード」フォルダに保存されます。

  2. ファイルをダブルクリックすると、注意が出ます

    右のような画面が出たら、「完了」を押して閉じます。「ゴミ箱に入れる」は押さないでください。押してしまったときは、もう一度ダウンロードすれば大丈夫です。

  3. 「プライバシーとセキュリティ」を開く

    画面左上の アップルマーク →「システム設定」を開き、左の一覧から「プライバシーとセキュリティ」を選びます。右側をいちばん下までスクロールしてください。

  4. 「このまま開く」を押して、パスワードを入れる

    もう一度確認が出るので「このまま開く」を押し、Mac にログインするときのパスワード（または Touch ID）で許可します。これでファイルが開きます。

  5. アプリを「アプリケーション」に入れる

    開いたウィンドウで、左の Creatte Tool のアイコンを右の Applications（アプリケーション）フォルダへドラッグします。

  6. アプリを開く（もう一度だけ同じ注意が出ます）

    「アプリケーション」フォルダの Creatte Tool をダブルクリックします。手順2と同じ注意が出たら、手順2〜4をもう一度くり返してください。今度は「“Creatte Tool”は Mac を保護するためにブロックされました」と表示されます。

  7. 完了！次からはふつうに開けます

    注意が出るのは最初の1回だけです。Dock に追加しておくと便利です。

Windows

Windows に入れる

注意は「ダウンロードするとき（ブラウザ）」と「インストーラーを開くとき（青い画面）」に出ることがあります。管理者権限は不要です。

  1. ファイルをダウンロードする

    ダウンロード欄の「Windows 版をダウンロード」を押します（ここから直接ダウンロード）。Snapdragon など ARM のパソコンは「ARM 版」を選びます。

  2. ブラウザに止められたら「保存」する

    Edge の場合：ダウンロード一覧の項目にマウスを合わせ、「…」→「保存」を選びます。さらに確認が出たら「詳細表示」→「保持する」を押します。

    Chrome の場合：「保存」（または「ダウンロードを続ける」）を押します。

  3. ファイルを開き、青い画面で「詳細情報」を押す

    ダウンロードした .msi ファイルをダブルクリックします。青い画面が出たら、文章の下にある小さな「詳細情報」を押します。

  4. 「実行」を押す

    アプリ名と「発行元：不明な発行元」が表示され、「実行」ボタンが出てきます。これを押すとインストーラーが始まります。

  5. インストーラーを進める（英語の画面です）

    Next（次へ）を押していき、保存先はそのままで Install（インストール）、最後に Finish（完了）を押します。「Create a desktop shortcut」にチェックを入れると、デスクトップにアイコンができます。

  6. 完了！スタートメニューから開けます

    スタートメニューで「Creatte」と入力すると出てきます。注意が出るのは最初の1回だけです。

Troubleshooting

うまくいかないとき

Mac：「このまま開く」ボタンが見つからない

ボタンが出るのは、ファイルを開こうとしてから約1時間以内です。もう一度ファイルをダブルクリックして注意を出し、「完了」で閉じてから、すぐに「プライバシーとセキュリティ」を開いてください。それでも出ないときは、次の「ターミナルで開く方法」を試してください。

Mac：ターミナルで開く方法（上級者向け）

「アプリケーション」→「ユーティリティ」→「ターミナル」を開き、次の1行を貼り付けて Enter を押します。ダウンロードしたファイルの「確認待ち」の印を外すコマンドです。そのあとファイルをダブルクリックすれば、注意なしで開けます。

xattr -d com.apple.quarantine ~/Downloads/creatte-tool-0.2.1-macos-universal.dmg

ファイルを「ダウンロード」以外に保存した場合は、xattr -d com.apple.quarantine （最後に半角スペース）まで入力してから、ファイルをターミナルにドラッグして Enter を押します。

Windows：「詳細情報」を押しても「実行」が出ない／「Smart App Control によってブロックされました」と出る

Windows 11 の「スマート アプリ コントロール」がオンになっていると、署名のないアプリは開けません。「設定」→「プライバシーとセキュリティ」→「Windows セキュリティ」→「アプリとブラウザーの制御」→「スマート アプリ コントロールの設定」で状態を確認できます。オフにするとほかのアプリにも影響するため、会社や学校のパソコンでは必ず管理者に相談してください。

会社・学校のパソコンでインストールできない

管理者がアプリのインストールを制限していることがあります。この場合は、IT 担当の方にこのページを見せて、Creatte Tool を許可してもらってください。導入サポートもご相談いただけます。

本当に安全ですか？

Creatte Tool のプログラムはすべて GitHub で公開されていて、だれでも中身を確認できます。ダウンロードページのファイルは、その公開されたプログラムから GitHub 上で自動的に作られたものです。注意が出るのは、Apple・Microsoft への有料の署名登録をしていないためで、ウイルスが見つかったという意味ではありません。必ずこのサイトのダウンロード欄から入手してください。

ダウンロードしたファイルが本物か確かめたい（上級者向け）

ダウンロード欄の SHA-256 チェックサム に、各ファイルの「指紋」（SHA-256）が書いてあります。Mac はターミナルで shasum -a 256 ファイル名、Windows は PowerShell で Get-FileHash ファイル名 を実行し、同じ文字列なら本物です。
