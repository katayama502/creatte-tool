Features

入れる、そろえる、すぐ開く

ワンクリックでインストール

OS と CPU に合ったパッケージ（DMG・MSI・AppImage・deb・rpm）を自動で選択。配布元が公開する SHA-256 チェックサムと照合してから入れます。

アップデートをまとめて

新しいバージョンが出たら通知。「すべてアップデート」で全アプリを一度に最新にできます。途中で止めても、続きから再開します。

日本語でわかりやすく

画面はすべて日本語に対応。丸ゴシック体を同梱しているので、フォントを追加しなくてもきれいに表示されます。メニューバーやタスクトレイからも起動できます。

How it works

はじめ方は3ステップ

  1. Creatte Tool を入れる

    macOS・Windows・Linux 用のインストーラーを実行します。管理者権限は不要です（Windows）。

  2. 使いたいアプリを選ぶ

    カードの「インストール」を押すだけ。ダウンロードと検証、インストールまで自動です。

  3. あとはおまかせ

    新しいバージョンが出たら通知が届きます。ボタン1つで最新に。

FAQ

よくある質問

本当に無料で使えますか？

はい。Creatte Tool と収録アプリ12本は、いずれも MIT または Apache-2.0 のオープンソースライセンスで公開されており、個人・商用を問わず無料で使えます。有料なのは、スクールや法人向けの導入サポートだけです。

Photoshop や Word のファイルは開けますか？

対応しているファイル形式はアプリごとに異なります。多くのアプリは開発初期の段階のため、業務で使う前に、お手持ちのファイルで試していただくことをおすすめします。

ダウンロードしたアプリは安全ですか？

アプリは各アプリの GitHub Releases からだけ取得し、配布元が公開している SHA-256 チェックサムと一致した場合にのみインストールします。ソースコードはすべて公開されています。

対応している OS は？

macOS（Apple シリコン / Intel）、Windows、Linux（deb・rpm・Flatpak・AppImage）、FreeBSD に対応しています。

元になったソフトウェアはありますか？

Creatte Tool は、オープンソースの ArtCraft Launcher と Craft App Suite をもとに、Creatte が日本語化・デザインの刷新などの改変を加えたものです。元のソフトウェアの著作権表示とライセンスは、アプリ内と配布物に含めています。Creatte Tool は独立した製品で、ArtCraft の開発元とは提携・承認の関係にありません。
