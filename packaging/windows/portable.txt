Creatte Tool portable mode

While this file sits next to creatte-tool.exe, Creatte Tool keeps its settings, its
download cache and its record of installed apps in the CreatteToolData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move Creatte Tool with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Creatte Tool) instead.
If CreatteToolData can't be written (for example on a read-only drive), Creatte Tool says
so and uses %APPDATA%\Creatte Tool instead.
